## 基督城米其林说明

《MICHELIN Guide New Zealand 2026》中，基督城有两家一星餐厅：`Inati` 和 `Tussock Hill`。`Inati` 周日、周一休息；`Tussock Hill` 仅供应午市。按本行程 2/14 傍晚抵达基督城、2/15 当天往返凯库拉的安排，两家均无法排入，页面未作虚假预留。

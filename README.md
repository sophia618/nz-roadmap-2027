## 说明

航班与巴士时间以出票和运营方最终通知为准。已记录航班：彭 `AC791 + QF3194`、`UA731 + UA8292`；索 `CA687`、`NZ550 + CA784`。酒店目前为建议住宿，并非已确认订单。

酒店品牌按官方酒店目录核对。截至 2026-11-18，[万豪新西兰酒店目录](https://www.marriott.com/en-us/hotel-sitemap/new-zealand-hotel-sitemap)仅列出奥克兰的 JW Marriott Auckland 和 Four Points by Sheraton Auckland；皇后镇暂无万豪系酒店。

已确认住宿：`Haka House Lake Tekapo`，2/12 入住，CAD 630.53 已付款。计划续住 2/13 一晚、2/14 退房；13 号续住仍待确认。住客姓名待确认，后续可能需联系酒店添加索的名字。

库克山：2/13 不在库克山住宿，改为蒂卡波当天往返。2/14 需预约 06:20 的包车，从蒂卡波带行李去库克山机场；包车需保管两件大行李并在活动结束后送到 Hermitage。

2/10 瓦纳卡计划：去程 `InterCity 08:10-09:56`，NZD 80，不可退；回程 `SkyDrive 16:15-17:40`。SkyDrive 可在发车前 1 小时修改预订。两家为分开承运，需分别购票。行程以 Lakefront / Station Park / That Wanaka Tree / 湖景午餐 / 皮划艇或湖边休息 / Ardmore St 购物为主，不安排 Lismore Park 上坡线。

2/11 米尔福德方案待定：RealNZ 官网大巴往返 + 游船 NZD 319/人起，大巴进飞机回 NZD 904/人；携程 2/11 大巴进出 + 游船 ¥1,142/人，套餐 F 车去飞回 ¥3,560/人。下单前需核对取消条款、是否含餐以及飞机停飞后的改大巴保障。

2/12 皇后镇到蒂卡波计划乘 `InterCity 08:05-12:05`。

2/13 晚 Dark Sky 推荐 Crater Experience（English）22:30 开始、75 分钟，NZD 139/人，含 Cowan’s Private Observatory 接驳。Crater 与 Summit 都位于 Aoraki Mackenzie 国际暗夜保护区；Summit 位于保护区核心的约翰山山顶，为 NZD 239、1 小时 45 分，包含专业天文台和 16 英寸望远镜，但本次 2/13 只剩凌晨场，会明显压缩睡眠，因此只列为体验升级参考。2/12 Crater 仅日语团，不列入。

## 基督城米其林说明

《MICHELIN Guide New Zealand 2026》中，基督城有两家一星餐厅：`Inati` 和 `Tussock Hill`。`Inati` 周日、周一休息；`Tussock Hill` 仅供应午市。按本行程 2/14 约 19:00 抵达基督城、2/15 当天往返凯库拉的安排，两家均无法排入，页面未作虚假预留。
